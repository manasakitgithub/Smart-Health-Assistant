# Smart Health Assistant

A Java + MySQL based Smart Health Assistant project.
It helps patients to book appointments, check symptoms, manage patient records and get health suggestions.

## Features
- Patient Registration & Login
- Doctor Appointment Booking
- Symptom Checker
- Health Records Management
- Admin Dashboard

## Technologies Used
- Java (Eclipse)
- MySQL Database
- JDBC

## How To Run This Project

1. Download SmartHealthAssistant.zip
2. Open Eclipse > File > Import > Existing Projects into Workspace > Select the ZIP
3. Open MySQL Workbench > Import smart_health_db.sql
4. Run the project in Eclipse

## Project Files
- SmartHealthAssistant.zip - Full Java Source Code
- smart_health_db.sql - Database File
